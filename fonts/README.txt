Put TrueType/OpenType fonts (.ttf, .otf, .ttc) in this folder to use them in the game.

In Options > Graphics, set "Font Style" to "Smooth", then pick the font in the "Font" field
below it. The fonts are drawn in the size and colors of the graphics pack's pixel fonts.

Characters the chosen font doesn't have are taken from the other fonts in this folder.
So to play in Japanese, Korean or Chinese, add a font that has those characters
(for example Noto Sans CJK), and keep your favorite font selected for the Latin letters.
Russian needs a font with Cyrillic letters (DejaVu Sans, Noto Sans and most others have them).
These languages always use the smooth font, as the pixel fonts can't show them.
